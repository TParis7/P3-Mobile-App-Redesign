Everything shown is backed by real data, with one deliberate exception. Match percentages are excluded because no per-mentor score exists in the API. Mentee avatars use the web platform's gradient and industry glyph treatment, never a photograph. Resources salary bands and skill counts come from the bundled web corpus (guide/lib/pathways.json), not from the CMS, which does not carry those fields. They are only true once that corpus ships with the app.

Build note: the campus wallpaper and the frosted surfaces are gone. On a phone there are no gutters for a watermark to live in, so it sat behind body text and dropped some copy to 1.64:1 contrast. It was also the only reason cards were translucent, which was the only reason a blur was in the spec. Cards are now opaque white on the flat #ECE6DF canvas, so @react-native-community/blur is not needed at all (it was never in package.json). Two non-flat surfaces remain by choice: the welcome gradient and the maroon hero band.
