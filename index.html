August 2026 · A fresh coat of paint · iPhone
Same app, same flows, same screens. This is a visual refresh that brings the mobile app into the web platform's design language, plus a small number of genuinely new items that are already built and proven on web (opportunity filters and imagery, richer career resources). Nothing here changes the app's architecture or navigation, which keeps the risk of breaking something low.
Scroll inside a phone. Tap its tab bar to jump between screens.

What is actually new here: opportunity imagery and filters (industry, deadline, location), career resources with salary and skills depth, a Videos tab with the same Featured / Latest / Following / Saved views the web app already has, and the frosted surface treatment. Everything else is the existing app, repainted.

Build note: React Native has no backdrop-filter. The frosted surfaces need @react-native-community/blur, and heavy blur on long lists is costly on low-end Android, so plan a solid rgba(255,255,255,0.94) fallback. The layout must read without the blur.

Mentor photos and video thumbnails are real P3 people and real posts. The background is the same campus-bg.jpg the web platform composites at 40% over #ECE6DF.
