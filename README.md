# P3 Mobile — Redesign Concept

Static, self-contained concept page for the P3 mobile app redesign.

- **Live:** https://tparis7.github.io/P3-Mobile-App-Redesign/
- **Companion:** https://tparis7.github.io/P3-AppStore-Preview/ (same visual language and page structure)

## What it is

A **visual refresh**, not a rebuild. Same flows, same navigation, same screens, repainted in the
P3 web platform's design language. The only genuinely new items are ones already built and proven
on web: opportunity imagery and filters, richer career resources, and the Videos tab's
Featured / Latest / Following / Saved views.

## How to use it

Toggle **Mentee / Mentor**. Scroll inside any phone. Tap a phone's tab bar to jump the strip to
that screen.

## Assets

Real P3 assets throughout: the app icon, the horizontal wordmark, Bricolage Grotesque and
Plus Jakarta Sans, `campus-bg.jpg`, real mentor photographs, and video thumbnails cropped from
real posts in the live app.
